# Интернационализация (i18n)

## Обзор

Приложение поддерживает три языка:
- **Английский** (en) — по умолчанию
- **Польский** (pl)
- **Русский** (ru)

Файлы локализации хранятся в общем пакете `packages/i18n` и используются веб-приложением.

## Архитектура

```
packages/i18n/
└── src/locales/
    ├── en.json    # Английские переводы
    ├── pl.json    # Польские переводы
    └── ru.json    # Русские переводы
        ↓
apps/web/src/lib/i18n.ts    # Инициализация svelte-i18n
        ↓
apps/web/src/routes/        # Компоненты используют $t('key')
```

## Веб-приложение (SvelteKit)

### Библиотека

Используется **svelte-i18n** для управления переводами.

### Инициализация

Файл: `apps/web/src/lib/i18n.ts`

- Регистрирует все файлы локализации
- Определяет язык браузера
- Использует английский, если локаль недоступна
- Сохраняет выбранную локаль в `localStorage`

### Использование в компонентах

```svelte
<script>
  import { t } from 'svelte-i18n';
</script>

<h1>{$t('dashboard.title')}</h1>
<p>{$t('dashboard.welcome', { values: { name: user.name } })}</p>
```

### Переключатель языка

Веб-приложение включает компонент переключения языка:
1. Показывает текущую локаль (флаг/название)
2. Список доступных локалей
3. При выборе: обновляет локаль svelte-i18n и сохраняет в localStorage

## ИИ-агент

Chat Agent поддерживает мультиязычные ответы:
- Системный промпт указывает ИИ отвечать на языке пользователя
- Определение языка по содержанию сообщения
- Поддержка разговоров на EN, PL, RU

## Добавление нового языка

1. Создать новый файл локализации в `packages/i18n/src/locales/` (например, `de.json`)
2. Скопировать структуру из `en.json` и перевести все значения
3. Зарегистрировать локаль в `apps/web/src/lib/i18n.ts`
4. Добавить опцию локали в компонент переключения языка
