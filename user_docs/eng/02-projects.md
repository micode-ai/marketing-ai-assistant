# Projects

## Overview

Projects are the core organizational unit in Marketing AI Assistant. Each project represents a marketing initiative, product, or client and contains all related content, campaigns, documents, and analytics.

## Creating a Project

1. Navigate to the **Dashboard**
2. Click **New Project**
3. Fill in the project details:

| Field | Description | Required |
|-------|-------------|----------|
| Name | Project name (e.g., "Website Redesign Campaign") | Yes |
| Description | Brief overview of the project goals | No |
| Website URL | Your project's website | No |
| Target Audience | Who you're marketing to (e.g., "Tech-savvy millennials") | No |
| Industry | Business sector (e.g., "SaaS", "E-commerce") | No |
| Brand Voice | Tone and style preferences for content | No |
| Goals | Key performance indicators and objectives | No |

4. Click **Create**

## Project Dashboard

Once you open a project, you'll see an overview page with:

- **Project stats** — content count, campaign count, checklist progress
- **Quick actions** — create content, start campaign, generate checklist
- **Recent activity** — latest changes and AI generations

## Project Sections

### Content

Create and manage all marketing content for the project:
- **Social Posts** — Twitter, LinkedIn, Facebook, Instagram
- **Blog Articles** — long-form content
- **Emails** — email copy
- **Newsletters** — recurring email content
- **Ad Copy** — advertising text
- **Landing Pages** — web page content

Each content item has a status workflow:
```
DRAFT → REVIEW → APPROVED → PUBLISHED
                          ↘ REJECTED
```

Content supports **version history** — every time you edit the body, a new version is automatically saved.

### Campaigns

Organize content into marketing campaigns:

| Campaign Type | Description |
|--------------|-------------|
| Email | Email-focused campaigns |
| Social | Social media campaigns |
| Blog | Content marketing campaigns |
| Multi-Channel | Campaigns spanning multiple channels |

Campaign statuses:
```
DRAFT → SCHEDULED → ACTIVE → COMPLETED
                         ↘ PAUSED
```

### Email

Manage email marketing within the project:
- **Email Lists** — create subscriber lists
- **Subscribers** — add and manage subscribers
- **Send Campaigns** — compose and send emails to your lists

### Checklists

Track marketing tasks with checklists:

| Checklist Type | Use Case |
|---------------|----------|
| Launch | Product or feature launch preparation |
| Weekly | Recurring weekly marketing tasks |
| Campaign Prep | Pre-campaign setup tasks |
| SEO | Search engine optimization tasks |
| Social Media | Social media management tasks |
| Email Campaign | Email campaign preparation |
| Competitive Analysis | Competitor research tasks |
| Custom | Any custom task list |

Each item can be assigned a **priority** (Low, Medium, High, Critical) and a **due date**.

### Documents

Generate and store marketing documents:

| Document Type | Description |
|--------------|-------------|
| Marketing Plan | Comprehensive marketing strategy |
| Report | Performance or analysis report |
| Competitive Analysis | Competitor comparison study |
| Brand Guidelines | Brand identity documentation |
| Content Calendar | Content scheduling plan |
| Proposal | Marketing proposal for stakeholders |
| Presentation | Marketing presentation material |

### Calendar

View your content schedule in a calendar format. See when content is planned to be published and campaign dates.

### Analytics

Track project performance:
- **Metrics** — page views, email opens, clicks, conversions
- **Summary** — high-level performance overview
- **Trends** — performance over time (configurable date range)

## Project Settings

Configure project-specific settings:
- Update project name, description, and details
- Modify brand voice preferences
- Set project goals and KPIs
- Archive the project when no longer active

## Archiving Projects

To archive a project:
1. Go to **Project Settings**
2. Click **Archive Project**
3. Confirm the action

Archived projects are hidden from the main list but not deleted. They can still be accessed if needed.

## AI Content Generation

Within any project section, you can use AI to generate:
- Marketing content (posts, articles, emails)
- Checklists with prioritized tasks
- Documents (marketing plans, reports, analyses)

The AI uses your project's context (target audience, brand voice, industry) to generate relevant, on-brand content.
