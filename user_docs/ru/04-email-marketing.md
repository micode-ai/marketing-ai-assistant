# Email-маркетинг

## Обзор

Marketing AI Assistant включает полноценную систему email-маркетинга. Вы можете управлять списками подписчиков, составлять email-кампании, отправлять письма и отслеживать результаты — всё внутри вашего проекта.

## Настройка email

### Добавление email-аккаунта

Перед отправкой писем необходимо подключить email-аккаунт:

1. Перейдите в **Настройки > Email-аккаунты**
2. Нажмите **Добавить аккаунт**
3. Выберите провайдера:

**SMTP (для собственных email-серверов):**
- Email-адрес (отправитель)
- Отображаемое имя
- SMTP-хост (напр., smtp.gmail.com, smtp.yandex.ru)
- SMTP-порт (напр., 587)
- Логин и пароль

**Resend (современный email API):**
- Email-адрес (отправитель)
- Отображаемое имя
- API-ключ от вашего аккаунта Resend

4. Нажмите **Сохранить**

Учётные данные шифруются и хранятся безопасно.

### Тестирование с MailHog (Разработка)

В режиме разработки письма перехватываются MailHog:
- Письма отправляются на SMTP MailHog, порт 1025
- Просмотр всех отправленных писем на **http://localhost:8025**
- Письма не доставляются реальным получателям

Идеально для тестирования email-кампаний без отправки реальных писем.

## Управление списками подписчиков

### Создание списка рассылки

1. Откройте ваш проект
2. Перейдите в раздел **Email**
3. Нажмите **Новый список**
4. Введите название и описание
5. Нажмите **Создать**

### Добавление подписчиков

1. Откройте список рассылки
2. Нажмите **Добавить подписчика**
3. Введите:
   - **Email** — email подписчика
   - **Имя** — имя подписчика (необязательно)
4. Нажмите **Добавить**

Если подписчик с таким email уже существует в списке, его информация будет обновлена.

### Статусы подписчиков

| Статус | Значение |
|--------|----------|
| Активный | Может получать письма |
| Отписался | Отказался через ссылку отписки |
| Отклонён (Bounce) | Постоянная ошибка доставки |

## Отправка email-кампаний

### Составление email-кампании

1. Перейдите в раздел **Email** проекта
2. Нажмите **Отправить кампанию**
3. Заполните:
   - **Кампания** — выберите кампанию
   - **Email-аккаунт** — с какого аккаунта отправлять
   - **Список подписчиков** — кому отправлять
   - **Тема письма** — заголовок email
   - **HTML-содержимое** — тело письма

### Использование плейсхолдеров

В HTML email можно использовать плейсхолдеры, которые автоматически заменяются для каждого подписчика:

| Плейсхолдер | Заменяется на | Пример |
|-------------|---------------|--------|
| `{{email}}` | Email подписчика | ivan@example.com |
| `{{unsubscribe_url}}` | Уникальная ссылка отписки | https://api.example.com/email/unsubscribe/abc123 |

**Важно:** Всегда включайте `{{unsubscribe_url}}` в письма. Это обязательно для соблюдения законодательства и практик email-маркетинга.

### Пример HTML email

```html
<html>
<body>
  <h1>Ежемесячная рассылка</h1>
  <p>Здравствуйте, {{email}},</p>
  <p>Вот главные маркетинговые новости этого месяца...</p>

  <hr>
  <p style="font-size: 12px; color: #666;">
    Не хотите получать эти письма?
    <a href="{{unsubscribe_url}}">Отписаться</a>
  </p>
</body>
</html>
```

### Отправка

1. Проверьте содержимое письма и список получателей
2. Нажмите **Отправить**
3. Система отправляет индивидуальные письма каждому активному подписчику
4. Каждый подписчик получает персонализированное письмо с уникальной ссылкой отписки
5. Статистика кампании записывается

## Процесс отписки

Когда подписчик нажимает ссылку отписки:
1. Он перенаправляется на эндпоинт отписки
2. Статус меняется с **Активный** на **Отписался**
3. Подписчик больше не будет получать письма из этого списка
4. Дата отписки записывается

## Email-шаблоны

### Просмотр шаблонов

1. Перейдите в **Шаблоны** в основной навигации
2. Просматривайте доступные email-шаблоны по категориям
3. Предварительный просмотр перед использованием

### Использование шаблона

1. Выберите шаблон
2. HTML шаблона загрузится в редактор
3. Настройте содержимое для вашей кампании
4. Добавьте плейсхолдеры (`{{email}}`, `{{unsubscribe_url}}`)
5. Отправьте

## Лучшие практики

- **Всегда включайте ссылку отписки** — это требование законодательства
- **Тестируйте через MailHog** перед отправкой реальным подписчикам
- **Сегментируйте списки** — создавайте отдельные списки для разных аудиторий
- **Персонализируйте** — используйте плейсхолдеры для обращения к подписчикам
- **Следите за bounce** — удаляйте «отказавших» подписчиков для здоровья списка
- **Пишите ясные темы** — от них зависит, откроют ли ваше письмо
