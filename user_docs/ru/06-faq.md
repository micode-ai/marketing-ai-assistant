# Часто задаваемые вопросы (FAQ)

## Общие вопросы

### Что такое Marketing AI Assistant?

Marketing AI Assistant — это платформа автоматизации маркетинга на основе ИИ, которая помогает создавать контент, управлять кампаниями, отправлять email-рассылки, генерировать маркетинговые документы и отслеживать аналитику. Используется модель OpenAI GPT-4o для генерации маркетинговых материалов, адаптированных под ваш бренд.

### Какие языки поддерживает приложение?

Интерфейс доступен на:
- Английском (English)
- Польском (Polski)
- Русском

ИИ-чат ассистент также поддерживает разговоры на всех трёх языках.

### Нужна ли банковская карта для регистрации?

Нет. Вы можете создать бесплатный аккаунт и использовать план FREE без карты. Карта нужна только при обновлении до PRO или ENTERPRISE.

## Аккаунт и вход

### Не могу войти. Что делать?

- Убедитесь, что используете правильный email и пароль
- Проверьте, не включен ли Caps Lock
- Если регистрировались через Google, используйте кнопку **Войти через Google**
- Попробуйте обновить страницу и войти заново

### Забыл пароль. Как восстановить?

Обратитесь к администратору вашей организации для сброса пароля или используйте функцию восстановления на странице входа.

### Можно ли сменить email?

Обратитесь к администратору организации для смены email.

### Как удалить аккаунт?

Обратитесь к Владельцу вашей организации для удаления из организации.

## ИИ-контент

### Как работает генерация контента ИИ?

ИИ использует контекст вашего проекта (целевая аудитория, голос бренда, отрасль, цели) вместе с вашим запросом (тема, тон, платформа) для генерации маркетингового контента через модель OpenAI GPT-4o.

### Сгенерированный контент уникален?

Да, каждая генерация создаёт уникальный контент. Тем не менее, всегда рекомендуется проверять и редактировать ИИ-контент перед публикацией.

### Можно ли редактировать ИИ-контент?

Безусловно. ИИ-контент сохраняется как черновик, который вы можете свободно редактировать и персонализировать. ИИ даёт отличную отправную точку.

### Что делать, если результат ИИ не устраивает?

Вы можете:
- Сгенерировать заново с другими параметрами
- Изменить тон (профессиональный, неформальный, юмористический, формальный)
- Выбрать другой тип контента или платформу
- Указать более конкретную тему и ключевые слова
- Отредактировать результат вручную

### Сколько ИИ-генераций доступно?

| План | Месячный лимит |
|------|---------------|
| FREE | 50 |
| PRO | 500 |
| ENTERPRISE | Без ограничений |

## Email-маркетинг

### Как начать отправку email?

1. Добавьте email-аккаунт в **Настройки > Email-аккаунты**
2. Создайте список рассылки в разделе Email проекта
3. Добавьте подписчиков
4. Составьте и отправьте кампанию

### Зачем нужна ссылка отписки?

Это требование законодательства о email-маркетинге (CAN-SPAM, GDPR). Используйте плейсхолдер `{{unsubscribe_url}}` в HTML, и система автоматически сгенерирует уникальную ссылку отписки для каждого подписчика.

### Что происходит при отписке?

Статус подписчика меняется на «Отписался», и он больше не будет получать письма из этого списка. Отписка записывается с отметкой времени.

### Можно ли импортировать подписчиков?

В текущей версии подписчики добавляются по одному через API или веб-интерфейс. Массовый импорт может быть добавлен в будущих обновлениях.

### Какие email-провайдеры поддерживаются?

- **SMTP** — любой SMTP-сервер (Gmail, Яндекс, Mail.ru, собственный)
- **Resend** — современный email API сервис

## Биллинг

### Как обновить план?

Перейдите в **Настройки > Биллинг** и нажмите **Обновить** рядом с желаемым планом. Вы будете перенаправлены на безопасную страницу оплаты Stripe.

### Можно ли понизить план?

Да, перейдите в **Настройки > Биллинг > Управление подпиской** и измените план через портал Stripe.

### Когда обновляется расчётный период?

Расчётный период обновляется ежемесячно от даты первой подписки.

### Какие способы оплаты принимаются?

Stripe принимает основные кредитные карты (Visa, Mastercard, American Express) и другие способы оплаты в зависимости от региона.

### Как отменить подписку?

Перейдите в **Настройки > Биллинг > Управление подпиской** и нажмите **Отменить план** в портале Stripe. Доступ сохраняется до конца текущего расчётного периода.

## Публикация в соцсетях

### Как опубликовать контент в социальных сетях?

1. Подключите социальные аккаунты в **Настройки > Интеграции**
2. Откройте элемент контента со статусом ОДОБРЕН или ОПУБЛИКОВАН
3. Нажмите **Опубликовать** и выберите, в какие аккаунты публиковать
4. Система отправит публикацию на каждую выбранную платформу

### Какие социальные платформы поддерживаются?

- **LinkedIn** — подключение через OAuth (нажмите Подключить, авторизуйтесь)
- **Twitter/X** — ручной ввод учётных данных (API-ключи и токены)
- **Facebook** — подключение через OAuth (выберите страницу для публикации)
- **Telegram** — ручной ввод (токен бота и ID чата)

### Почему публикация в соцсети не удалась?

Проверьте историю публикаций для подробностей об ошибке. Частые причины:
- Истёкшие OAuth-токены (переподключите аккаунт)
- Контент превышает лимит символов платформы
- Достигнут лимит запросов API

## Расширенные функции

### Как работает отслеживание SEO-ключевых слов?

Добавьте ключевые слова в разделе **SEO** вашего проекта. Для каждого ключевого слова можно:
- Указать поисковый интент (Информационный, Навигационный, Коммерческий, Транзакционный)
- Привязать к целевому URL
- Записывать позиции в поиске для отслеживания прогресса

### Что такое A/B-тестирование?

A/B-тестирование позволяет сравнивать варианты тем писем, контента или лендингов. Создайте тест, добавьте варианты (A, B и т.д.), запустите тест и отслеживайте показы и конверсии для определения победителя.

### Как работают вебхуки?

Вебхуки отправляют уведомления на ваши URL при наступлении событий (напр., контент опубликован, кампания отправлена). Payload подписывается HMAC-SHA256. Настройте их в **Настройки > Вебхуки**.

### Можно ли отслеживать посетителей сайта?

Да. Каждый проект имеет **трекинг-сниппет** (JavaScript), который можно встроить на ваш сайт. Он отслеживает просмотры страниц, идентифицирует пользователей и передаёт данные в аналитику проекта. Также доступен трекинг-пиксель для email.

## Техническое

### Какие браузеры поддерживаются?

Приложение работает во всех современных браузерах:
- Chrome (рекомендуется)
- Firefox
- Safari
- Edge

### Мои данные в безопасности?

- Все пароли зашифрованы bcrypt
- Учётные данные email-аккаунтов зашифрованы AES-256
- Используются JWT-токены с коротким сроком действия
- Helmet устанавливает заголовки безопасности
- CORS настроен для предотвращения несанкционированного доступа

### Могу ли я напрямую использовать API?

Доступ к API доступен на плане **ENTERPRISE**. Документация API доступна по адресу `/api/docs` (Swagger UI).
