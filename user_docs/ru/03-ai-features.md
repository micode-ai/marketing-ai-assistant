# Возможности ИИ

## Обзор

Marketing AI Assistant использует модель OpenAI GPT-4o для создания маркетингового контента, генерации документов, составления чек-листов и предоставления стратегических рекомендаций. Все ИИ-функции работают с контекстом вашего проекта — голосом бренда, целевой аудиторией и отраслью — для создания релевантных материалов.

## Генерация контента ИИ

### Как это работает

1. Перейдите в раздел **Контент** вашего проекта
2. Нажмите **Сгенерировать с ИИ**
3. Настройте параметры генерации:
   - **Тип контента** — какой контент создать
   - **Платформа** — для какой соцсети или канала
   - **Тема** — предмет контента
   - **Ключевые слова** — важные термины для включения
   - **Тон** — стиль написания (профессиональный, неформальный, юмористический, формальный)
   - **Длина** — короткий, средний или длинный

4. Нажмите **Сгенерировать**
5. ИИ создаёт контент с учётом руководства по бренду вашего проекта
6. Просмотрите, отредактируйте и опубликуйте

### Типы контента

| Тип | Описание | Подходит для |
|-----|----------|-------------|
| Пост в соцсетях | Короткий контент для соцсетей | Twitter, LinkedIn, Facebook, Instagram |
| Статья для блога | Длинная статья с разделами | Корпоративный блог, контент-маркетинг |
| Email | Текст для email-маркетинга | Рассылки, промо-письма |
| Рассылка | Периодический email-контент | Еженедельные/ежемесячные обновления |
| Рекламный текст | Рекламные объявления | Google Ads, Facebook Ads, LinkedIn Ads |
| Лендинг | Контент для веб-страницы | Лендинги кампаний |

### Советы для лучших результатов

- **Заполните данные проекта** — чем больше контекста (целевая аудитория, голос бренда, отрасль), тем лучше результат
- **Конкретизируйте тему** — «Запуск SaaS-продукта Q1 2026 для ИТ-директоров» даст лучший результат, чем «запуск продукта»
- **Используйте ключевые слова** — включите важные термины, которые должны присутствовать в контенте
- **Итерируйте** — генерируйте несколько вариантов и комбинируйте лучшие части
- **Редактируйте результат** — ИИ даёт отличную отправную точку; всегда проверяйте и персонализируйте

## Шаблоны

Раздел **Шаблоны** в главном меню содержит готовые маркетинговые шаблоны, которые генерируются ИИ персонально для вашего проекта.

### Шаблоны чек-листов

| Шаблон | Тип | Описание |
|--------|-----|----------|
| Запуск продукта | LAUNCH | Полный чек-лист от исследования до пост-запуска |
| Email-кампания | EMAIL_CAMPAIGN | Стратегия, подготовка списка, тестирование, аналитика |
| SEO-аудит | SEO | Технический SEO, on-page, контент, линкбилдинг |
| Запуск в соцсетях | SOCIAL_MEDIA | Стратегия, контент-план, сообщество, аналитика |
| Подготовка кампании | CAMPAIGN_PREP | Стратегия, креатив, техническая настройка, запуск |

### Шаблоны документов

| Шаблон | Тип | Описание |
|--------|-----|----------|
| Маркетинговый план | MARKETING_PLAN | Квартальный стратегический документ |
| Отчёт об эффективности | REPORT | Отчёт на основе **реальных данных проекта** |
| Анализ конкурентов | COMPETITIVE_ANALYSIS | Исследование рынка и конкурентов |

### Как это работает

1. Перейдите в **Шаблоны** в главном меню
2. Нажмите на нужный шаблон
3. Если проект не выбран — появится выбор проекта
4. ИИ начнёт генерацию (30-60 секунд) — вы увидите индикатор загрузки
5. После завершения вас перенаправит на страницу чек-листов или документов

### Особенности

- **Персонализация** — ИИ учитывает название, отрасль, целевую аудиторию и сайт вашего проекта
- **Язык** — контент генерируется на языке вашего интерфейса (русский, английский, польский)
- **Подробные описания** — каждый пункт чек-листа содержит мини-гайд на 6-10 предложений с конкретными инструментами, шагами и метриками
- **Реальные данные** — шаблон «Отчёт об эффективности» анализирует реальные данные проекта (контент, кампании, подписчики, соцсети, чеклисты) и не придумывает метрики

## Генерация чек-листов ИИ

### Как это работает

1. Перейдите в раздел **Чек-листы** вашего проекта
2. Нажмите **Сгенерировать с ИИ**
3. Выберите тип чек-листа:
   - **Запуск** — подготовка к запуску продукта/функции
   - **Еженедельный** — регулярные маркетинговые задачи
   - **Подготовка кампании** — задачи перед кампанией
   - **SEO** — поисковая оптимизация
   - **Социальные сети** — управление соцсетями
   - **Email-кампания** — подготовка email-рассылки

4. Добавьте контекст, описывающий ваши потребности (необязательно)
5. Нажмите **Сгенерировать**

### Что вы получите

- 25-35 задач, сгруппированных по 4-6 секциям
- Каждая задача с подробным описанием (6-10 предложений): конкретные шаги, инструменты, метрики, типичные ошибки
- Приоритеты: Критический (4-6 задач), Высокий (8-10), Средний и Низкий
- Первая секция раскрыта по умолчанию, остальные свёрнуты

### Переключение между чек-листами

Когда в проекте несколько чек-листов, вверху страницы Чек-листов появляются вкладки:
- Каждая вкладка показывает название чек-листа и процент выполнения
- Нажмите на вкладку, чтобы просмотреть этот чек-лист
- Завершённые чек-листы отмечены зелёным индикатором прогресса

## Генерация документов ИИ

### Как это работает

1. Перейдите в раздел **Документы** вашего проекта
2. Нажмите **Сгенерировать с ИИ**
3. Выберите тип документа:
   - **Маркетинговый план** — комплексный документ стратегии
   - **Отчёт** — отчёт о результатах или анализ
   - **Конкурентный анализ** — сравнение с конкурентами
   - **Руководство по бренду** — документация фирменного стиля
   - **Контент-календарь** — план публикации контента
   - **Предложение** — маркетинговое предложение для заинтересованных сторон
   - **Презентация** — маркетинговая презентация
   - **Бриф для Product Hunt** — слоган, описание, комментарий создателя, посты в соцсетях в день запуска

4. Укажите тему и дополнительный контекст
5. Нажмите **Сгенерировать**

### Что вы получите

- Структурированный Markdown-документ с заголовками и разделами
- Практические рекомендации, адаптированные под ваш проект
- Аналитические выводы на основе контекста проекта

## Генерация стратегии ИИ

### Как это работает

1. Перейдите в проект и запустите агента **Стратегия**
2. Выберите тип стратегии:
   - **GTM** — стратегия выхода на рынок
   - **Позиционирование** — анализ позиционирования бренда
   - **Product Hunt** — стратегия запуска на Product Hunt
   - **Ценообразование** — рекомендации по ценовой стратегии
3. Добавьте тему и контекст
4. Нажмите **Сгенерировать**

ИИ генерирует структурированный документ, охватывающий позиционирование, конкурентный ландшафт, канальную стратегию, распределение бюджета и KPI.

## Генерация email ИИ

### Как это работает

1. Запустите агента **Email** из вашего проекта
2. Выберите тип генерации:
   - **Тема письма** — несколько вариантов для A/B-тестирования с прогнозом открываемости
   - **Email-кампания** — полный текст письма (тема + прехедер + тело + CTA)
   - **Последовательность** — полная цепочка писем (несколько email с рекомендациями по таймингу)
3. Укажите тему и тон
4. Нажмите **Сгенерировать**

## ИИ-чат ассистент

### Как это работает

1. Нажмите **ИИ-чат** в основной навигации
2. При создании нового чата выберите контекст:
   - **Организация** — общие вопросы без привязки к проекту
   - **Конкретный проект** — ИИ загрузит контекст проекта (описание, аудитория, отрасль)
3. Введите ваш вопрос или запрос
4. ИИ ответит маркетинговыми рекомендациями

### Контекст чата

В заголовке чата отображается текущий контекст в формате «хлебных крошек»:
- **Организация > Проект** — если выбран проект
- **Организация > Проект не выбран** — если чат на уровне организации

При выборе существующей сессии чата проект автоматически восстанавливается из сессии.

В боковой панели сессий под каждым названием показан проект или «Чат организации».

### О чём можно спросить

- **Вопросы стратегии**: «Какие маркетинговые каналы использовать для запуска B2B SaaS?»
- **Идеи для контента**: «Предложи 10 тем для блога финтех-стартапа»
- **Помощь с email**: «Напиши тему письма для кампании Чёрной пятницы»
- **SEO-советы**: «Какие ключевые слова таргетировать для органического трафика?»
- **Планирование кампаний**: «Как структурировать 3-месячный план контент-маркетинга?»
- **Аналитика**: «Какие метрики отслеживать для email-маркетинга?»

### Контекстный чат

Если вы выберете проект при начале чата, ИИ загрузит контекст проекта:
- Описание и цели проекта
- Информацию о целевой аудитории
- Предпочтения голоса бренда
- Специфику отрасли

Это означает, что ИИ даст советы, специально адаптированные под ваш проект.

### Мультиязычная поддержка

ИИ-чат поддерживает разговоры на:
- **Английском**
- **Польском**
- **Русском**

Пишите на предпочитаемом языке, и ИИ ответит на том же языке.

### Создание ресурсов из чата

Вы можете попросить ИИ-чат создавать маркетинговые ресурсы напрямую:

- **«Создай чек-лист для запуска»** — генерирует чек-лист через агента Checklist
- **«Сгенерируй пост для LinkedIn о нашем продукте»** — создаёт контент через агента Content
- **«Напиши стратегию выхода на рынок»** — создаёт документ стратегии
- **«Проведи SEO-аудит»** — выполняет SEO-анализ
- **«Создай email-кампанию»** — генерирует текст email-маркетинга

Когда вы просите ИИ что-то создать, он запускает соответствующего агента и отвечает подтверждением и прямой ссылкой на результаты.

**Важно:** Для создания ресурсов необходимо выбрать проект. Если проект не выбран, ИИ попросит вас выбрать его.

### Форматированные ответы

Ответы ИИ-чата отображаются с полным Markdown-форматированием:
- **Заголовки** для структурированного контента
- **Жирный** и *курсивный* текст для акцентов
- Маркированные и нумерованные списки
- `Блоки кода` для технического контента
- [Ссылки]() на соответствующие страницы

### Управление сообщениями и сессиями

- **Удалить сообщение** — наведите курсор на сообщение и нажмите кнопку удаления
- **Удалить сессию** — нажмите иконку корзины рядом с сессией, появится окно подтверждения
- Для активной сессии кнопка удаления всегда видна; для остальных — при наведении
- Только вы (создатель сессии чата) можете удалять сообщения

## Многоязычная генерация контента

### Обзор

Вы можете генерировать контент на английском, польском и русском языках одновременно одним нажатием кнопки. ИИ создаёт три отдельные версии контента — по одной на каждый язык — каждая адаптирована естественно для своего языка, а не переведена машинным способом.

### Как это работает

1. Перейдите в раздел **Контент** вашего проекта
2. Нажмите **Сгенерировать с ИИ**
3. Настройте параметры контента как обычно
4. Включите **Сгенерировать на всех языках**, чтобы создать версии EN/PL/RU одновременно
5. Нажмите **Сгенерировать**

Все три версии сгруппированы вместе и отображаются как одна карточка в списке контента с языковыми метками (EN, PL, RU), показывающими доступные версии.

### Просмотр языковых версий

- Карточка контента показывает все доступные языковые метки
- Нажмите на метку, чтобы переключиться на соответствующую языковую версию
- Каждую версию можно редактировать, одобрять и публиковать независимо

### Ручное создание на нескольких языках

Используйте кнопку **Создать контент** (рядом с **Сгенерировать с ИИ**) для написания контента вручную. Вы также можете выбрать создание сразу на всех 3 языках — откроются три отдельные вкладки редактора, по одной для каждого языка.

## Markdown-редактор

Весь контент редактируется в Markdown-редакторе с разделённым экраном:

- **Левая панель** — пишите и редактируйте в Markdown
- **Правая панель** — живой предпросмотр, рендерящийся в реальном времени

### Панель инструментов

| Кнопка | Действие |
|--------|----------|
| **Ж** Жирный | Оборачивает выделение в `**жирный**` |
| *К* Курсив | Оборачивает выделение в `*курсив*` |
| H1 | Вставляет `# Заголовок 1` |
| H2 | Вставляет `## Заголовок 2` |
| Список | Вставляет `- маркированный список` |
| Ссылка | Вставляет `[текст](url)` |
| Изображение | Вставляет `![alt](url)` |

### Полноэкранный редактор

Для сосредоточенного редактирования откройте специальный полноэкранный редактор:

1. Откройте элемент контента
2. Нажмите **Открыть полный редактор**
3. Редактор открывается по адресу `/projects/[id]/content/[contentId]/edit`
4. Используйте разделённый экран для написания и предпросмотра одновременно

## Работа с изображениями

### Загрузка изображений

Прикрепляйте изображения непосредственно к контенту:

1. В редакторе контента нажмите кнопку **Загрузить изображение** или перетащите файл в область редактора
2. Поддерживаемые форматы: JPEG, PNG, WebP
3. Максимальный размер файла: 5 МБ
4. Изображение загружается, а Markdown-тег вставляется в позицию курсора

### Генерация изображений ИИ

Создавайте изображения из текстового описания с помощью DALL-E 3:

1. В редакторе контента нажмите **Сгенерировать изображение**
2. Введите описание нужного изображения (например, «минималистичный баннер для запуска SaaS-продукта»)
3. Нажмите **Сгенерировать**
4. Сгенерированное изображение прикрепляется к контенту и вставляется в редактор

Изображения, созданные ИИ, засчитываются в лимит генераций вашего плана.

## Отслеживание использования ИИ

Каждая ИИ-генерация отслеживается:
- **Запуски агентов** — просмотр всех генераций для проекта
- **Статус** — ожидание, выполнение, завершено или ошибка
- **Использование токенов** — сколько ИИ-токенов использовано
- **Стоимость** — оценочная стоимость каждой генерации

## Лимиты по плану

| План | ИИ-генераций в месяц |
|------|---------------------|
| FREE | 50 |
| PRO | 500 |
| ENTERPRISE | Без ограничений |

По достижении лимита нужно дождаться следующего расчётного периода или обновить план.
