# Возможности ИИ

## Обзор

Marketing AI Assistant использует модель OpenAI GPT-4o для создания маркетингового контента, генерации документов, составления чек-листов и предоставления стратегических рекомендаций. Все ИИ-функции работают с контекстом вашего проекта — голосом бренда, целевой аудиторией и отраслью — для создания релевантных материалов.

## Генерация контента ИИ

### Как это работает

1. Перейдите в раздел **Контент** вашего проекта
2. Нажмите **Сгенерировать с ИИ**
3. Настройте параметры генерации:
   - **Тип контента** — какой контент создать
   - **Платформа** — для какой соцсети или канала
   - **Тема** — предмет контента
   - **Ключевые слова** — важные термины для включения
   - **Тон** — стиль написания (профессиональный, неформальный, юмористический, формальный)
   - **Длина** — короткий, средний или длинный

4. Нажмите **Сгенерировать**
5. ИИ создаёт контент с учётом руководства по бренду вашего проекта
6. Просмотрите, отредактируйте и опубликуйте

### Типы контента

| Тип | Описание | Подходит для |
|-----|----------|-------------|
| Пост в соцсетях | Короткий контент для соцсетей | Twitter, LinkedIn, Facebook, Instagram |
| Статья для блога | Длинная статья с разделами | Корпоративный блог, контент-маркетинг |
| Email | Текст для email-маркетинга | Рассылки, промо-письма |
| Рассылка | Периодический email-контент | Еженедельные/ежемесячные обновления |
| Рекламный текст | Рекламные объявления | Google Ads, Facebook Ads, LinkedIn Ads |
| Лендинг | Контент для веб-страницы | Лендинги кампаний |

### Советы для лучших результатов

- **Заполните данные проекта** — чем больше контекста (целевая аудитория, голос бренда, отрасль), тем лучше результат
- **Конкретизируйте тему** — «Запуск SaaS-продукта Q1 2026 для ИТ-директоров» даст лучший результат, чем «запуск продукта»
- **Используйте ключевые слова** — включите важные термины, которые должны присутствовать в контенте
- **Итерируйте** — генерируйте несколько вариантов и комбинируйте лучшие части
- **Редактируйте результат** — ИИ даёт отличную отправную точку; всегда проверяйте и персонализируйте

## Генерация чек-листов ИИ

### Как это работает

1. Перейдите в раздел **Чек-листы** вашего проекта
2. Нажмите **Сгенерировать с ИИ**
3. Выберите тип чек-листа:
   - **Запуск** — подготовка к запуску продукта/функции
   - **Еженедельный** — регулярные маркетинговые задачи
   - **Подготовка кампании** — задачи перед кампанией
   - **SEO** — поисковая оптимизация
   - **Социальные сети** — управление соцсетями
   - **Email-кампания** — подготовка email-рассылки

4. Добавьте контекст, описывающий ваши потребности (необязательно)
5. Нажмите **Сгенерировать**

### Что вы получите

- Элементы задач с чёткими, выполнимыми описаниями
- Назначенные приоритеты (Низкий, Средний, Высокий, Критический)
- Логический порядок задач

## Генерация документов ИИ

### Как это работает

1. Перейдите в раздел **Документы** вашего проекта
2. Нажмите **Сгенерировать с ИИ**
3. Выберите тип документа:
   - **Маркетинговый план** — комплексный документ стратегии
   - **Отчёт** — отчёт о результатах или анализ
   - **Конкурентный анализ** — сравнение с конкурентами
   - **Руководство по бренду** — документация фирменного стиля
   - **Контент-календарь** — план публикации контента
   - **Предложение** — маркетинговое предложение для заинтересованных сторон
   - **Презентация** — маркетинговая презентация
   - **Бриф для Product Hunt** — слоган, описание, комментарий создателя, посты в соцсетях в день запуска

4. Укажите тему и дополнительный контекст
5. Нажмите **Сгенерировать**

### Что вы получите

- Структурированный Markdown-документ с заголовками и разделами
- Практические рекомендации, адаптированные под ваш проект
- Аналитические выводы на основе контекста проекта

## Генерация стратегии ИИ

### Как это работает

1. Перейдите в проект и запустите агента **Стратегия**
2. Выберите тип стратегии:
   - **GTM** — стратегия выхода на рынок
   - **Позиционирование** — анализ позиционирования бренда
   - **Product Hunt** — стратегия запуска на Product Hunt
   - **Ценообразование** — рекомендации по ценовой стратегии
3. Добавьте тему и контекст
4. Нажмите **Сгенерировать**

ИИ генерирует структурированный документ, охватывающий позиционирование, конкурентный ландшафт, канальную стратегию, распределение бюджета и KPI.

## Генерация email ИИ

### Как это работает

1. Запустите агента **Email** из вашего проекта
2. Выберите тип генерации:
   - **Тема письма** — несколько вариантов для A/B-тестирования с прогнозом открываемости
   - **Email-кампания** — полный текст письма (тема + прехедер + тело + CTA)
   - **Последовательность** — полная цепочка писем (несколько email с рекомендациями по таймингу)
3. Укажите тему и тон
4. Нажмите **Сгенерировать**

## ИИ-чат ассистент

### Как это работает

1. Нажмите **ИИ-чат** в основной навигации
2. Введите ваш вопрос или запрос
3. ИИ ответит маркетинговыми рекомендациями

### О чём можно спросить

- **Вопросы стратегии**: «Какие маркетинговые каналы использовать для запуска B2B SaaS?»
- **Идеи для контента**: «Предложи 10 тем для блога финтех-стартапа»
- **Помощь с email**: «Напиши тему письма для кампании Чёрной пятницы»
- **SEO-советы**: «Какие ключевые слова таргетировать для органического трафика?»
- **Планирование кампаний**: «Как структурировать 3-месячный план контент-маркетинга?»
- **Аналитика**: «Какие метрики отслеживать для email-маркетинга?»

### Контекстный чат

Если вы выберете проект при начале чата, ИИ загрузит контекст проекта:
- Описание и цели проекта
- Информацию о целевой аудитории
- Предпочтения голоса бренда
- Специфику отрасли

Это означает, что ИИ даст советы, специально адаптированные под ваш проект.

### Мультиязычная поддержка

ИИ-чат поддерживает разговоры на:
- **Английском**
- **Польском**
- **Русском**

Пишите на предпочитаемом языке, и ИИ ответит на том же языке.

## Отслеживание использования ИИ

Каждая ИИ-генерация отслеживается:
- **Запуски агентов** — просмотр всех генераций для проекта
- **Статус** — ожидание, выполнение, завершено или ошибка
- **Использование токенов** — сколько ИИ-токенов использовано
- **Стоимость** — оценочная стоимость каждой генерации
