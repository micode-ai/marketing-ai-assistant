# Публикация в социальных сетях

## Обзор

Marketing AI Assistant позволяет публиковать контент напрямую в социальные сети из приложения. Подключите социальные аккаунты один раз, а затем публикуйте одобренный контент в несколько кликов.

## Поддерживаемые платформы

| Платформа | Метод подключения | Что публикуется |
|-----------|-------------------|-----------------|
| LinkedIn | OAuth 2.0 (нажмите Подключить) | Текстовые посты через LinkedIn API |
| Twitter/X | Ручной ввод API-учётных данных | Твиты через Twitter API v2 |
| Facebook | OAuth 2.0 (выберите страницу) | Посты на странице через Graph API v19 |
| Telegram | Ручной ввод (токен бота + ID чата) | Сообщения через Telegram Bot API |

## Подключение аккаунтов

### Настройки > Интеграции

1. Перейдите в **Настройки > Интеграции**
2. Вы увидите карточки для каждой платформы

### LinkedIn

1. Нажмите **Подключить** на карточке LinkedIn
2. Вы будете перенаправлены на LinkedIn для авторизации
3. Предоставьте запрашиваемые разрешения
4. Вы будете перенаправлены обратно — аккаунт отобразится как подключённый

**Необходимые переменные окружения:** `LINKEDIN_CLIENT_ID`, `LINKEDIN_CLIENT_SECRET`

### Twitter/X

1. Нажмите **Подключить** на карточке Twitter
2. Введите ваши API-учётные данные:
   - **App Key** (API Key)
   - **App Secret** (API Secret)
   - **Access Token**
   - **Access Secret**
3. Нажмите **Сохранить**

Для получения этих учётных данных необходим аккаунт разработчика Twitter с доступом к API.

### Facebook

1. Нажмите **Подключить** на карточке Facebook
2. Вы будете перенаправлены на Facebook для авторизации
3. Выберите **Страницу**, на которой хотите публиковать
4. Предоставьте запрашиваемые разрешения
5. Вы будете перенаправлены обратно с подключённой страницей

**Необходимые переменные окружения:** `FACEBOOK_APP_ID`, `FACEBOOK_APP_SECRET`

### Telegram

1. Нажмите **Подключить** на карточке Telegram
2. Введите:
   - **Токен бота** — от BotFather
   - **ID чата** — ID канала или группы
3. Нажмите **Сохранить**

## Публикация контента

### Со страницы контента

1. Откройте раздел **Контент** вашего проекта
2. Найдите контент со статусом **ОДОБРЕН** или **ОПУБЛИКОВАН**
3. Нажмите кнопку **Опубликовать**
4. В модальном окне выберите подключённые аккаунты для публикации
5. Нажмите **Опубликовать**

### Статус публикации

Каждая попытка публикации отслеживается:

| Статус | Значение |
|--------|----------|
| PENDING | Публикация в процессе |
| PUBLISHED | Успешно опубликовано на платформе |
| FAILED | Произошла ошибка (проверьте сообщение об ошибке) |

### Просмотр истории публикаций

1. Откройте элемент контента
2. Просмотрите историю публикаций:
   - Платформа и аккаунт
   - Статус (Ожидание / Опубликовано / Ошибка)
   - URL поста (если опубликован)
   - Сообщение об ошибке (если не удалось)
   - Временная метка

## Публикация с учётом языка

### Язык по умолчанию для социального аккаунта

Каждому подключённому социальному аккаунту можно назначить **язык по умолчанию**. Это указывает системе, какую языковую версию контента использовать при публикации в данный аккаунт.

Например:
- Ваш аккаунт LinkedIn настроен на **английский**
- Ваша страница Facebook настроена на **польский**
- Ваш канал Telegram настроен на **русский**

### Публикация многоязычного контента

Когда вы публикуете контент с несколькими языковыми версиями (EN/PL/RU), система автоматически сопоставляет нужную языковую версию с каждым аккаунтом на основе его настройки языка по умолчанию:

1. Нажмите **Опубликовать** на карточке многоязычного контента
2. Выберите аккаунты для публикации
3. Система автоматически выбирает правильную языковую версию для каждого аккаунта
4. Проверьте соответствие и нажмите **Опубликовать**

Если для аккаунта не задан язык по умолчанию, вам будет предложено выбрать языковую версию для отправки в этот аккаунт.

### Установка языка по умолчанию

1. Перейдите в **Настройки > Интеграции**
2. Нажмите **Редактировать** на подключённом аккаунте
3. Выберите **Язык по умолчанию** (английский, польский или русский)
4. Сохраните изменения

## Управление аккаунтами

### Отключение

1. Перейдите в **Настройки > Интеграции**
2. Нажмите **Отключить** на аккаунте, который хотите удалить
3. Подтвердите действие

### Истечение токенов

OAuth-токены (LinkedIn, Facebook) могут истекать. Если публикация не удалась с ошибкой авторизации, переподключите аккаунт для обновления токенов.

## Безопасность

Все учётные данные социальных аккаунтов и OAuth-токены зашифрованы при хранении с использованием шифрования AES-256-CBC — тот же стандарт безопасности, что применяется для учётных данных email-аккаунтов.
