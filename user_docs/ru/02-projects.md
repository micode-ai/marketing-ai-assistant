# Проекты

## Обзор

Проекты — основная организационная единица в Marketing AI Assistant. Каждый проект представляет маркетинговую инициативу, продукт или клиента и содержит весь связанный контент, кампании, документы и аналитику.

## Создание проекта

1. Перейдите на **Панель управления**
2. Нажмите **Новый проект**
3. Заполните данные проекта:

| Поле | Описание | Обязательно |
|------|----------|-------------|
| Название | Название проекта (напр., «Кампания редизайна сайта») | Да |
| Описание | Краткий обзор целей проекта | Нет |
| URL сайта | Сайт вашего проекта | Нет |
| Целевая аудитория | На кого направлен маркетинг | Нет |
| Отрасль | Сфера бизнеса (напр., «SaaS», «E-commerce») | Нет |
| Голос бренда | Предпочтения по тону и стилю контента | Нет |
| Цели | Ключевые показатели и задачи | Нет |

4. Нажмите **Создать**

## Панель проекта

При открытии проекта вы увидите обзорную страницу:

- **Статистика проекта** — количество контента, кампаний, прогресс чек-листов
- **Быстрые действия** — создать контент, начать кампанию, сгенерировать чек-лист
- **Последняя активность** — недавние изменения и ИИ-генерации

## Разделы проекта

### Контент

Создание и управление маркетинговым контентом:
- **Посты в соцсетях** — Twitter, LinkedIn, Facebook, Instagram
- **Статьи для блога** — длинный контент
- **Emails** — текст для email-рассылок
- **Рассылки** — регулярный email-контент
- **Рекламные тексты** — тексты для рекламы
- **Лендинги** — контент для веб-страниц

Каждый элемент контента имеет рабочий процесс по статусам:
```
ЧЕРНОВИК → ПРОВЕРКА → ОДОБРЕН → ОПУБЛИКОВАН
                            ↘ ОТКЛОНЁН
```

Контент поддерживает **историю версий** — при каждом редактировании тела контента автоматически сохраняется новая версия.

### Кампании

Организация контента в маркетинговые кампании:

| Тип кампании | Описание |
|-------------|----------|
| Email | Email-кампании |
| Социальные сети | Кампании в социальных сетях |
| Блог | Кампании контент-маркетинга |
| Мультиканальная | Кампании на нескольких каналах |

Статусы кампаний:
```
ЧЕРНОВИК → ЗАПЛАНИРОВАНА → АКТИВНА → ЗАВЕРШЕНА
                              ↘ ПРИОСТАНОВЛЕНА
```

### Email

Управление email-маркетингом в проекте:
- **Списки рассылки** — создание списков подписчиков
- **Подписчики** — добавление и управление подписчиками
- **Отправка кампаний** — составление и отправка писем

### Чек-листы

Отслеживание маркетинговых задач:

| Тип чек-листа | Применение |
|---------------|-----------|
| Запуск | Подготовка к запуску продукта |
| Еженедельный | Регулярные маркетинговые задачи |
| Подготовка кампании | Задачи перед кампанией |
| SEO | Задачи поисковой оптимизации |
| Социальные сети | Управление соцсетями |
| Email-кампания | Подготовка email-кампании |
| Конкурентный анализ | Исследование конкурентов |
| Пользовательский | Любой список задач |

Каждый элемент может иметь **приоритет** (Низкий, Средний, Высокий, Критический) и **срок выполнения**.

### Документы

Генерация и хранение маркетинговых документов:

| Тип документа | Описание |
|--------------|----------|
| Маркетинговый план | Комплексная маркетинговая стратегия |
| Отчёт | Отчёт о результатах или анализ |
| Конкурентный анализ | Сравнение с конкурентами |
| Руководство по бренду | Документация по фирменному стилю |
| Контент-календарь | План публикации контента |
| Предложение | Маркетинговое предложение |
| Презентация | Маркетинговая презентация |

### Календарь

Просмотр расписания контента в формате календаря. Видны даты запланированных публикаций и сроки кампаний.

### Аналитика

Отслеживание эффективности проекта:
- **Метрики** — просмотры, открытия email, клики, конверсии
- **Сводка** — общий обзор эффективности
- **Тренды** — динамика за настраиваемый период

## Настройки проекта

- Обновление названия, описания и деталей
- Изменение голоса бренда
- Установка целей и KPI
- Архивация проекта

## Архивация проектов

1. Перейдите в **Настройки проекта**
2. Нажмите **Архивировать проект**
3. Подтвердите действие

Архивированные проекты скрыты из основного списка, но не удалены.

## ИИ-генерация контента

В любом разделе проекта вы можете использовать ИИ для генерации:
- Маркетингового контента (посты, статьи, email)
- Чек-листов с приоритизированными задачами
- Документов (маркетинговые планы, отчёты, анализы)

ИИ использует контекст проекта (целевая аудитория, голос бренда, отрасль) для генерации релевантного контента.
