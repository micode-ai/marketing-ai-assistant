# Projekty

## Przeglad

Projekty to podstawowa jednostka organizacyjna w Marketing AI Assistant. Kazdy projekt reprezentuje inicjatywe marketingowa, produkt lub klienta i zawiera wszystkie powiazane tresci, kampanie, dokumenty i analizy.

## Tworzenie projektu

1. Przejdz na **Panel glowny**
2. Kliknij **Nowy projekt**
3. Wypelnij dane projektu:

| Pole | Opis | Wymagane |
|------|------|----------|
| Nazwa | Nazwa projektu (np. „Kampania redesignu strony") | Tak |
| Opis | Krotki opis celow projektu | Nie |
| URL strony | Strona internetowa projektu | Nie |
| Grupa docelowa | Do kogo kierujesz marketing | Nie |
| Branza | Sektor biznesu (np. „SaaS", „E-commerce") | Nie |
| Glos marki | Preferencje tonu i stylu tresci | Nie |
| Cele | Kluczowe wskazniki i zadania | Nie |

4. Kliknij **Utworz**

## Panel projektu

Po otwarciu projektu zobaczysz strone przegladu:

- **Statystyki projektu** — liczba tresci, kampanii, postep list kontrolnych
- **Szybkie akcje** — tworzenie tresci, start kampanii, generowanie listy kontrolnej
- **Ostatnia aktywnosc** — najnowsze zmiany i generacje AI

## Sekcje projektu

### Tresci

Tworzenie i zarzadzanie tresciami marketingowymi:
- **Posty w mediach spolecznosciowych** — Twitter, LinkedIn, Facebook, Instagram
- **Artykuly na blog** — dlugie tresci
- **E-maile** — teksty e-mail marketingu
- **Newslettery** — regularne tresci e-mail
- **Teksty reklamowe** — teksty reklamowe
- **Landing page** — tresci stron docelowych

Kazdy element tresci ma przepyw statusow:
```
SZKIC → RECENZJA → ZATWIERDZONY → OPUBLIKOWANY
                            ↘ ODRZUCONY
```

Tresci obsluguja **historie wersji** — przy kazdej edycji automatycznie zapisywana jest nowa wersja.

### Kampanie

Organizacja tresci w kampanie marketingowe:

| Typ kampanii | Opis |
|-------------|------|
| E-mail | Kampanie e-mailowe |
| Media spolecznosciowe | Kampanie w mediach spolecznosciowych |
| Blog | Kampanie content marketingowe |
| Wielokanalowa | Kampanie na wielu kanalach |

Statusy kampanii:
```
SZKIC → ZAPLANOWANA → AKTYWNA → ZAKONCZONA
                          ↘ WSTRZYMANA
```

### E-mail

Zarzadzanie e-mail marketingiem w projekcie:
- **Listy mailingowe** — tworzenie list subskrybentow
- **Subskrybenci** — dodawanie i zarzadzanie subskrybentami
- **Wysylka kampanii** — komponowanie i wysylanie e-maili

### Listy kontrolne

Sledzenie zadan marketingowych:

| Typ listy kontrolnej | Zastosowanie |
|---------------------|-------------|
| Wprowadzenie | Przygotowanie do premiery produktu |
| Tygodniowa | Regularne zadania marketingowe |
| Przygotowanie kampanii | Zadania przed kampania |
| SEO | Optymalizacja dla wyszukiwarek |
| Media spolecznosciowe | Zarzadzanie mediami spolecznosciowymi |
| Kampania e-mail | Przygotowanie kampanii e-mailowej |
| Analiza konkurencji | Badanie konkurencji |
| Wlasna | Dowolna lista zadan |

Kazdy element moze miec **priorytet** (Niski, Sredni, Wysoki, Krytyczny) i **termin wykonania**.

### Dokumenty

Generowanie i przechowywanie dokumentow marketingowych:

| Typ dokumentu | Opis |
|--------------|------|
| Plan marketingowy | Kompleksowa strategia marketingowa |
| Raport | Raport wynikow lub analiza |
| Analiza konkurencji | Porownanie z konkurentami |
| Wytyczne marki | Dokumentacja tozsamosci marki |
| Kalendarz tresci | Plan publikacji tresci |
| Propozycja | Propozycja marketingowa |
| Prezentacja | Material prezentacyjny |

### Kalendarz

Przegladanie harmonogramu tresci w formacie kalendarza. Widoczne sa daty planowanych publikacji i terminy kampanii.

### Analityka

Sledzenie wydajnosci projektu:
- **Metryki** — wyswietlenia, otwarcia e-maili, klikniecia, konwersje
- **Podsumowanie** — ogolny przeglad wydajnosci
- **Trendy** — dynamika w konfigurowalnym okresie

## Ustawienia projektu

- Aktualizacja nazwy, opisu i szczegolow
- Zmiana glosu marki
- Ustawianie celow i KPI
- Archiwizacja projektu

## Archiwizacja projektow

1. Przejdz do **Ustawienia projektu**
2. Kliknij **Archiwizuj projekt**
3. Potwierdz akcje

Zarchiwizowane projekty sa ukryte z glownej listy, ale nie usuniete.

## Generowanie tresci AI

W kazdej sekcji projektu mozesz uzyc AI do generowania:
- Tresci marketingowych (posty, artykuly, e-maile)
- List kontrolnych z priorytetyzowanymi zadaniami
- Dokumentow (plany marketingowe, raporty, analizy)

AI wykorzystuje kontekst projektu (grupa docelowa, glos marki, branza) do generowania trafnych tresci.
